# 琴始 · 键盘钢琴

用电脑键盘学习钢琴的中文网页应用。纯 HTML、CSS 和 JavaScript，使用 Web Audio API 发声，无需安装依赖或配置后端。

## 功能

- 电脑键盘、鼠标和触屏弹奏，支持和弦与空格延音
- 4 种合成音色、音量调节和节拍器
- 分级曲库、5 项基础训练、示范播放和跟弹判定
- 沉浸式课程，含故事导入、瀑布流和简谱视图
- 跟弹和示范循环：默认 1 轮，可设为 1–20 轮，轮间停顿 2 秒，支持停止
- 练习完成情况保存在当前浏览器的 localStorage

## 本地运行

在仓库根目录运行：

```sh
python3 -m http.server 5173 --directory dist
```

浏览器打开 http://localhost:5173 ，点击“走进第一节课”。浏览器需要用户交互后才能播放声音。

白键：`A S D F G H J K L ; ' ]`；黑键：`W E T Y U O P`；空格：延音。

## 部署到 Cloudflare Pages（GitHub 自动部署）

1. 在 Cloudflare 控制台进入 **Workers & Pages → Create application → Pages**。
2. 选择 **Import an existing Git repository**，授权并选择 `EastAndWeast/piano`。
3. 配置如下：

| 设置 | 值 |
| --- | --- |
| 项目名称 | `piano`（如已占用，可换名称并同步修改 wrangler.jsonc 中的 name） |
| 生产分支 | `main` |
| 框架预设 | `None` |
| 根目录 | 仓库根目录（留空） |
| 构建命令 | `exit 0` |
| 输出目录 | `dist` |
| 环境变量 | 无需配置 |

4. 点击 **Save and Deploy**。成功后 Cloudflare 会提供实际的 `*.pages.dev` 地址。
5. 后续推送到 `main` 将触发自动部署。

此项目使用 **Pages**，创建时请选择 Pages，而非需要 Worker 入口的 Workers 部署流程。

官方参考：[静态 HTML 部署](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)、[Wrangler 配置](https://developers.cloudflare.com/pages/functions/wrangler-configuration/)。

## 文件结构

```text
dist/
  index.html   页面与资源入口
  style.css    学习空间和沉浸琴房样式
  app.js       琴键、音频、曲库、基础训练
```

`dist` 就是可直接部署的源文件目录，没有额外构建步骤。所有站内资源使用相对路径。

## 当前范围

曲库为内置简化旋律片段；音色为浏览器合成，并非真实钢琴采样。真人演奏参考使用外部视频，受网络与视频平台可用性影响。学习进度只保存在当前浏览器，不跨设备同步。

## 高手空间 · LIVE 舞台

打开 `pro.html`，或从新手空间点击“高手空间”。这是独立的舞台演奏页面，使用深色全屏视觉，与新手课堂分开。

- 极光、余烬、月白三套主题；实时光柱、粒子、音符和常见和弦反馈
- 双排电脑键盘覆盖两个八度，可整体升降两个八度；支持和弦、鼠标、触屏、延音
- 4 种合成音色、音量、余音、固定按键力度、节拍器
- 纯净舞台收起控制栏；另有浏览器全屏按钮
- 录下并在本机保存最近一段演奏，最长 2 分钟；支持 1 / 2 / 3 / 5 / 10 轮回放，轮间间隔 2 秒
- 页面隐藏时停止回放；录音自动结束保存，避免后台继续演奏

低音区：`Z S X D C V G B H N J M`；高音区：`Q 2 W 3 E R 5 T 6 Y 7 U I`。空格临时延音。

快捷键：`Shift + R` 开始／结束录音，`Shift + P` 回放，`Shift + H` 切换纯净舞台，`Escape` 停止回放并显示控制。

舞台录音保存的是带时序、时长和力度的琴键演奏数据，不是麦克风录音或音频文件。新录音会替换上一段；电脑键盘的多键支持取决于硬件。

### 舞台点歌与三种模式

LIVE 舞台新增点歌台，可按曲名／作者搜索、按难度筛选现有 12 首简化旋律片段。

- **自动弹奏**：合成演奏所选曲目，同步点亮琴键与舞台光效，支持调速、暂停和继续。
- **自由弹奏**：保留选曲信息，自由即兴，不进行跟弹判定。
- **学习弹奏**：自动匹配曲目音区，提示下一音及电脑按键；弹对后推进，显示准确率。

自动与学习模式支持 1–20 轮循环，默认 1 轮，轮间休息 2 秒。停止、切换模式、换曲或离开页面会取消待播放音符。页面隐藏时暂停曲目；开启现场录音时切换到自由弹奏，避免与自动演奏冲突。

所有选曲为单手简化片段；自动弹奏是浏览器教学合成，并非完整原版演奏或伴奏音频。

## 花园版界面

首页采用奶油卡通视觉和固定左导航布局，包含新手练习、舞台入口、选曲与三种弹奏模式。选择歌曲不会直接发声；点击主操作才开始。

`garden.css` 为首页、课程琴房、舞台与弹窗的共享视觉层；`garden.js` 负责首页选曲及模式入口；`garden-stage.js` 负责舞台主题与侧栏的配合。原有音频引擎和曲库仍由既有脚本维护。

支持窄屏布局、键盘焦点指示与系统“减少动态效果”设置。插画及生成提示见 `docs/mascot-prompt.txt`，改版说明见 `docs/garden-redesign.txt`。

## 打字追逐 · 警察抓小偷

打开 `typing.html`，或在首页／舞台的导航中点击“打字追逐”。看高亮的 A、S、D 等琴键字母，按对后弹出对应音符，并让警察逐步靠近小偷。按错不会跳过音符，也不会发出错误琴音。

- 6 种选曲：小星星、欢乐颂、两只老虎、玛丽有只小羊羔、伦敦桥、音符小镇巡游串烧
- 单遍使用更长的单手旋律练习编配；小星星为 42 音，巡游串烧为 136 音
- 支持 1 / 2 / 4 遍，默认 2 遍；最长串烧练习为 544 次按键
- 轻松模式不限时、不会失败；追逐／疾速模式目标分别为每分钟 45／75 键，停顿及失误会增加逃跑风险
- 暂停不计时，窗口离开或切到后台自动暂停；Escape 暂停；支持停止、重来、换歌
- 展示进度、准确率、连击与速度；成功通关后的最佳准确率／用时保存在本机
- 提供触屏输入和可点击琴键，支持系统减少动态效果设置

曲目是传统／公版旋律的游戏用单手编配，不是原版完整乐曲或录音。旋律由玩家正确按键逐音触发，不使用自动背景音乐代替练习。

相关文件：`chase-songs.js`（长曲编配）、`chase.js`（追逐状态与输入、音频）、`chase.css`（卡通场景与界面）。
